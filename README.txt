GeoSpoof Pro 2.4

NEW:
- Paste a coordinate pair directly into one box.
- Automatically separates latitude and longitude.
- Supports:
  - "24.251720753005618, 79.3964269953607"
  - "24.251720753005618 79.3964269953607"
  - "(24.251720753005618, 79.3964269953607)"
  - "lat: 24.251720753005618, lng: 79.3964269953607"
  - pasted text/URLs containing a valid coordinate pair
- Optional shop/location name.
- If no name is entered, Save automatically names it using the coordinates.
- Saved locations remain in My Shops.
- Apply, Edit, Delete continue to work.
- No default locations.

INSTALL:
1. Extract the ZIP.
2. Open chrome://extensions
3. Enable Developer mode.
4. Remove the old GeoSpoof Pro unpacked version or use Reload.
5. Click Load unpacked.
6. Select the GeoSpoof-Pro-2.4 folder.

USE:
Paste:
24.251720753005618, 79.3964269953607

Then click:
- Apply to Active Tab = use immediately
- Save = add to My Shops

The extension uses Chrome's native DevTools geolocation override.
It does not change IP/server-side geolocation.
