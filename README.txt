GeoSpoof Pro 2.1

INSTALL:
1. Extract the ZIP.
2. Open chrome://extensions
3. Turn Developer mode ON.
4. Click Load unpacked.
5. Select the GeoSpoof-Pro-2.1 folder.

USE:
1. Open the location-aware website.
2. Open GeoSpoof Pro.
3. Enter latitude/longitude, or choose a preset.
4. Click Apply to Active Tab.
5. Reload the website if it had already requested location.
6. Test its location feature.

TECHNICAL:
This extension uses Chrome DevTools Protocol:
Emulation.setGeolocationOverride

It does NOT change:
- public IP address
- GPS hardware
- Wi-Fi positioning
- server-side IP geolocation
- other anti-spoofing signals

Chrome may display a debugging indicator while the tab is attached.
